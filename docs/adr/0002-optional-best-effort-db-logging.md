# DB 記録は任意かつベストエフォートとする

本機の主機能は温湿度・気圧・THI の OLED 表示であり、DB へのデータ記録は副次的な位置づけとする。そのため (1) 設定ファイルが無ければ DB を初期化せず `None` として表示のみで起動し、(2) 保存は mpsc チャネルへの fire-and-forget として、INSERT の失敗は `eprintln!` で記録するだけでメインループ（センサー読み取り・表示）を止めない。

DB 障害や設定不備で常駐サービスの表示が止まることを避けるのが狙い。トレードオフとして、書き込み失敗時はデータが欠損し得る（リトライ・永続キューは持たない）。この欠損が許容できなくなった場合は再評価する。
